# EdgeHome 本地知识检索与能耗分析

阶段 8 的知识问答必须基于本地文档证据。索引使用 SQLite 保存小规模说明书、设备笔记和政策文档；所有 SQLite 调用通过 Home Assistant executor job 执行，并在异步层设置超时。

## 检索边界

- 文档必须具有本地来源标识、标题和内容；检索结果返回出处、片段和词法得分。
- 可将实体关联到设备型号，检索会限制在该型号对应的说明书中。
- 没有实体关联或没有文档命中时，结果明确为无证据；调用方必须说明无法依据本地资料回答，而不是猜测。
- 检索不读取网络、不会上传本地文档，也不授予模型执行设备服务的能力。

## 确定性能耗统计

能耗分析从 Home Assistant Recorder 的累计 `sum` 统计读取 kWh 样本。代码按时间排序并计算相邻样本差值；最后一个区间仅在至少有两段历史正能耗、且超过历史中位数两倍时标记异常。建议只陈述测得的 kWh、基线和检查方向，不直接关闭或调整设备，也不让模型计算原始时间序列。

## 对话查询

启用 EdgeHome 快速路径后，可使用只读命令 `查询说明书 vacuum.demo 如何清理滤网`，或使用未绑定设备的 `查询知识库 如何清理滤网`。系统只会返回本地索引中命中的说明书片段与来源；无命中时会明确拒绝依据资料作答。

能耗查询格式为 `分析 sensor.energy 最近24小时能耗`。查询仅读取 Recorder 的累计统计，不调用设备控制服务；统计不足或 Recorder 暂不可用时不会推测原因或给出建议。
