# EdgeHome 结构化多轮状态

EdgeHome 在 Home Assistant `ChatLog` 之外保存最小的结构化会话状态：上一条已验证计划、最近实体与参数、待澄清问题和过期时间。它不替代原始聊天记录，也不持久化模型原始提示词或全屋状态。

## 持久化与过期

状态使用 Home Assistant 异步 `Store` 保存，按 `conversation_id` 隔离，默认 12 小时过期。损坏或过期记录会被忽略/清理，不能阻断 Conversation。

## 受支持的引用

- “卧室的也一样”：仅在能唯一定位同域目标实体时复制上一条计划并替换实体与验证目标；
- “它再调亮一点”“它再调暗一点”：仅继承上一条亮度参数并以 10% 步进调整；
- “温度高一点”“温度低一点”：仅继承上一条温度参数并以 1°C 步进调整。

无法唯一定位、没有对应上一条计划或引用超出受支持范围时，不生成计划。所有引用计划仍会重新通过固定计划校验器。

## 延时任务

延时任务只接受“数字秒/分钟/小时后 + 单条命令”。内层命令先被转换为固定计划，再连同 UTC 执行时间保存到 Home Assistant Store。任务可按会话查询与取消，Home Assistant 重启后未来的待执行任务会重新注册；执行时由同一执行器再次校验并记录完成或失败，不会直接调用任意服务。

Conversation 会先恢复待澄清请求、尝试受限引用、处理延时任务，最后才进入普通快速路径或复杂模型规划。成功的计划会写回状态；澄清、模型失败或不支持的引用不会猜测实体，也不会绕过原 Conversation 回退路径。
