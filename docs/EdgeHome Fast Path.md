# EdgeHome 中文快速路径

本功能为 Home LLM 增加一条可选的、确定性的中文设备控制路径。它只处理单设备、单动作的高频指令；复杂任务仍交给原有对话流程，且默认不会启用这条新路径。

## 当前能力

第一项实现只完成理解层，尚未接入 Conversation：

- 识别开关、状态查询、亮度、温度和窗帘控制意图；
- 识别“然后”“定时”“如果”等复杂、多动作或条件表达，并拒绝直接执行；
- 解析阿拉伯数字和常见中文数字（例如“百分之五十”“二十六点五”）；
- 仅从已暴露给 Home Assistant 对话能力的实体中，通过友好名称、实体别名或区域组合名称匹配设备；
- 同名设备或缺少合法数值时不生成可执行计划。

该层不调用大模型、不调用 Home Assistant 服务，也不会更改现有 Conversation 行为。后续路由器只能把已通过本层约束的结果转为阶段 3 的固定计划。

## 固定计划路由与执行

快速路由器会为已确认的单设备指令生成且只生成一个 `TaskPlan`。实体、工具、参数、验证规则仍会经过阶段 3 的完整校验；快速路径不允许把用户文本转换为任意域/服务调用。

- 开关操作验证最终状态为 `on` 或 `off`；
- 亮度使用 Home Assistant 的 `brightness`（0–255）回读值验证，允许一个量化误差；
- 温度和窗帘位置分别验证 `temperature` 与 `current_position`；
- 状态查询只读取已暴露实体，不调用服务；
- 指令已经被快速路径接收后，即使执行失败也会直接报告失败，绝不会再次交给旧模型路径重复控制。
