# EdgeHome 环境感知与动态场景

阶段 7 只将任务相关的环境数据作为计划输入或执行前复核依据。它不会把全屋状态、传感器历史或任意实体暴露给模型。

## 环境选择和缓存

任务快照会先匹配用户明确提及的设备；“离家/安全检查”补充人员与门窗传感器，“温度/湿度/光照/天气”补充相应环境实体。快照按目标短时缓存，相关实体状态变化时可精确失效。

## 离家安全报告

报告只读：列出仍在家的人员、打开的门窗与不可用门窗。它不会因为离家请求而自动关门、关窗、上锁或关闭设备。

## 环境重校验

在模型规划和执行之间，会保存计划目标/前置条件的最小基线。实体离线或状态发生变化时，计划被拒绝并要求重新规划，不执行过时动作。

## 动态场景恢复

动态场景在执行前只保存其固定计划涉及的设备状态。恢复时根据这些快照生成新的固定计划：灯光恢复开关/亮度，开关和风扇恢复开关，窗帘恢复位置；不支持的设备域不会被猜测或恢复。恢复成功后才删除恢复点，失败时保留以供后续处理。
