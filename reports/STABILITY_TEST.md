# 一小时稳定性测试

## 条件

- 配置时长：3,600 秒；采样间隔：60 秒。
- 开始进程：2026-07-12 00:58:35（本机时区）。
- 工作负载：只读中文简单意图分类、`E3` 设备资料检索、家庭能耗分析、`http://127.0.0.1:8080/health` 本地模型健康检查和进程/系统资源采样。
- 不调用设备控制服务，不修改实际 Home Assistant 实体状态。

## 结果

| 指标 | 实测值 |
| --- | ---: |
| 样本数 | 60 |
| 首个 / 最后一个采样时刻 | 0.087 s / 3,540.504 s |
| 采样覆盖跨度 | 3,540.417 s |
| 稳定性执行器内存最小 / 最大 | 188.109 / 188.352 MiB |
| 首末内存变化 | +0.211 MiB |
| 系统 CPU 峰值 | 75.5% |
| 模型不健康次数 | 0 |
| 知识检索失败次数 | 0 |
| 能耗分析失败次数 | 0 |

循环条件以单调时钟检查 3,600 秒；第 60 个样本在 3,540.504 秒写入，随后程序按该周期剩余时间休眠并在到达配置时长后自然退出。因此数据样本跨度为 3,540.417 秒，而完整测试进程覆盖配置的一小时窗口；报告没有把缺少的末尾 60 秒伪造为一条采样记录。

结论：在这组只读本地核心工作负载下，模型端点持续可用，知识与能耗路径无失败，稳定性执行器没有观察到持续内存增长。该结论不等同于对 llama.cpp 容器、Home Assistant 容器或所有设备驱动的内存泄漏证明；它们应由更长时间、多负载的部署监控继续覆盖。
