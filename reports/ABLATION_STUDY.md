# 消融研究（已完成的可控行为探针）

本机已在 30 条独立 `response_format=json_schema` 复杂规划探针中取得 27/30 合法 JSON，但尚未对全部八项模块在同一端到端模型工作负载上重复运行。以下是已实际运行、且可从原始数据复核的模块级消融探针；未测维度明确标记为未测，而不是填充估计值。

| 模块 / 移除方式 | 实测探针 | 观测结果 | 原始来源 |
| --- | --- | --- | --- |
| 快速路径移除 | 50 简单请求改为全量模型 | 模型调用从 0 升至 50；平均 12.652→643.195 ms | `dual_path_results.csv` |
| 执行验证移除 | 50 次故障注入服务调用 | 最终完成率 100%→90%，假成功率 0%→10% | `execution_verification_comparison.csv` |
| 失败恢复移除 | 与执行验证同一注入 | 5 次未更新状态不再被重试恢复 | `execution_verification_comparison.csv` |
| 知识检索移除 | 20 本地资料任务 | 启用检索命中 19/20；未检索路径不产生资料证据 | `knowledge_workloads.csv` |
| 资源调度移除 | 内存 95% 注入探针 | 启用时 `template_fallback`；禁用将失去该保护分支 | `resource_scheduler_decisions.json` |
| 场景状态、结构化校验、安全冲突检测 | 单元和回归探针 | 已由第 11/12 阶段回归覆盖；本轮未以无效 JSON 模型执行伪造端到端数字 | `tests/` 与 103 项基线 |

该报告的结论是：验证、恢复、快速路径、检索与调度已经有真实、可重放数据；其余三项必须在 Schema 合法模型可用后运行完整消融，不能用理论数字替代。
