# SpaceButler 功能演示视频脚本

## 推荐成片

- 时长：3 分钟左右。
- 画面：1920×1080，浏览器缩放 90%～100%。
- 主线：自然语言任务 → 安全确认 → 真实设备回读 → 主动节能 → 事件追踪。
- 开拍地址：`http://127.0.0.1:8765/`。

## 开拍前检查

确认页面顶部可以正常切换以下四个视图：

1. AI 管家
2. 空间与设备
3. 主动服务
4. 执行事件

“空间与设备”应显示 3 个空间、12 台设备、12/12 在线；“主动服务”应显示客厅规则 5/5 条满足。

如果需要重新录制，可在 PowerShell 中执行：

```powershell
$base = "http://127.0.0.1:8765"
Invoke-RestMethod -Method Post -Uri "$base/api/preferences/clear" -ContentType "application/json" -Body "{}"
Invoke-RestMethod -Method Post -Uri "$base/api/chat/clear" -ContentType "application/json" -Body "{}"
$scene = @{ unoccupied_minutes = 23; occupied = $false; window_open = $true; climate_mode = "cool" } | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri "$base/api/scene/reset" -ContentType "application/json" -Body $scene
```

然后刷新页面并回到“AI 管家”。

## AI 管家演示用语

直接点击“多设备任务”即可自动提交以下内容：

> 打开卧室阅读灯到55%，关闭客厅电视，把客厅窗帘调到30%，空调设为25度制冷

计划生成后，右侧应出现四个步骤。点击“确认并执行”，最终应显示：

- 卧室阅读灯：开启，亮度 55% · PASS
- 客厅电视：关闭 · PASS
- 客厅窗帘：位置 30% · PASS
- 客厅空调：制冷，设定 25°C · PASS

## 可选加分镜头

如果视频允许增加 30～45 秒，可展示故障防护：

1. 在“主动服务”的“空调故障”中选择“ACK 状态不变”。
2. 写入测试状态并重新分析、确认执行。
3. 展示系统没有把 ACK 当成真实成功，而是根据状态回读报告验证失败。
4. 结束后将故障模式恢复为“正常”。

这一段用于强调系统具备“防假成功”和可解释失败能力。

## 60 秒精简版

1. 5 秒：标题和产品定位。
2. 12 秒：空间与设备，展示 12/12 在线。
3. 23 秒：多设备自然语言计划与四步回读 PASS。
4. 15 秒：主动服务 5/5 条件与节能建议。
5. 5 秒：执行事件链路和本地部署说明。

## 录制提示

- 开始录制后停留 2 秒再操作，切换页面后也停留约 1 秒，方便后期剪辑。
- 鼠标移动尽量慢，避免在设备长列表中快速滚动。
- 生成计划时可继续旁白，不要把等待过程完全剪掉；本地模型与安全校验是技术展示的一部分。
- 正式录制前先关闭无关通知，并确认浏览器页面没有红色错误提示。
