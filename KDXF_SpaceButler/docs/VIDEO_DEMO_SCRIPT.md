# SpaceButler 演示视频录制手册

## 这份文档对应的架构

- 设备：**10 台，全部经 ESPHome Native API 接入 Home Assistant**。已无 MQTT 链路。
- 品牌：10 台设备分属 5 个品牌生态（小米米家 / Aqara / 美的 / 鸿蒙智联 / Philips Hue），
  由适配器层翻译各自原生报文。
- Agent：LangGraph `observe → understand → activate → plan → execute → verify → respond`，
  自然语言由本地 Qwen2.5-7B 理解。
- 语音：长按 V 流式识别，松开后提交。
- 工作流：自然语言生成可审阅计划，拖拽编排，按真实设备执行。

## 一、开拍前（3 步，约 1 分钟）

```powershell
Set-Location KDXF_SpaceButler
python scripts\run_workbench.py --port 8765
```

打开 <http://127.0.0.1:8765>，进入左侧 **「演示控制台」**：

1. 点 **「就绪自检」** → 7 项全绿、右上角显示「可以开拍」才继续。
2. 点 **「一键重置」** → 等约 12 秒（窗帘全行程是真实计时），11 步全部打勾。
3. 切到 **「AI 管家」** 开始录制。演示控制台本身不需要入镜。

自检任何一项红了，先修，不要开录：

| 红项 | 含义与处理 |
|---|---|
| 本地模型 | 模型没起来。**Agent 会安全拒绝执行，不会退回固定脚本**，录出来是失败画面 |
| 模型上下文容量 | 每槽 < 4096 tokens。llama.cpp 把 `-c` 均分给 slot，槽位装不下带设备清单的规划 prompt 时结构化调用会 500，**规划静默退回确定性回退，画面里"AI 没参与"**。用 `-c 16384 --parallel 1` 启动 |
| 设备全部在线 | 有节点没起。`docker compose --profile local-esphome up -d` |
| 实体绑定无缺失 | HA 里有同名实体造成歧义。在 `.env` 用 `SPACEBUTLER_ENTITY_*` 显式绑定 |
| Agent 运行时 | 后台线程没存活或 mode 不是 llm |

## 二、3 分钟主线

| 时间 | 操作 | 旁白 |
|---|---|---|
| 00:00–00:15 | 停在「首页」全屋看板 | 「SpaceButler 是家庭空间的主动管家。它不只是执行命令，而是理解空间状态、规划任务并验证结果。」 |
| 00:15–00:40 | 进「空间设备」，指出设备卡片上的**品牌徽标** | 「这一屋子设备来自 5 个品牌生态：小米、Aqara、美的、鸿蒙、Hue。协议各不相同——MIoT 用 siid/piid，Zigbee 用簇命令，Hue 的亮度是 0 到 254。适配器层把它们统一成一套意图。」 |
| 00:40–01:20 | 回「AI 管家」，**长按 V** 说：<br>「我准备在客厅看会电影，有点热，灯别太亮。」 | 「先看语音。按住说话，字幕实时出现，松开才提交。」<br>计划出现后：「一句话被编译成环境约束，生成候选计划、预测未来状态、评分选优。执行后逐项回读真实设备状态。」<br>**动作数由模型按实时状态决定，不是固定脚本——旁白不要说死"三步"。** |
| 01:20–01:40 | 再问「现在适合看电影了吗？」 | 「同样的目标再问一次，它重新观察状态后输出**零动作**。这是 Agent 和 Chatbot 的分界。」 |
| 01:40–02:10 | 进「主动服务」，点「模拟人工调灯 45%」×3 | 「我手动改亮度。系统把它识别为人工纠正——区别于自己的动作和环境漂移——写入偏好观测。几次之后，规划会自动偏向这个亮度。我从没说过『记住我喜欢 45%』。」 |
| 02:10–02:40 | 点「注入热扰动 31°C」，然后**不要说话** | 「现在通过 ESPHome 固件服务注入真实热量。接下来我不说话——它自己感知目标偏离，重新规划并执行。」 |
| 02:40–03:00 | 进「工作流」，展示已保存流程 | 「复杂场景可以固化成工作流：自然语言生成、拖拽调整、按真实设备顺序执行。」 |

「演示控制台」里每个场景卡片都带完整旁白文本，录制时可以直接照读。

## 三、60 秒精简版

1. 8 秒：首页全屋看板 + 定位。
2. 12 秒：设备品牌徽标，点明 5 个生态、协议差异。
3. 22 秒：语音说出观影需求 → 多步计划 → 逐项回读 PASS。
4. 12 秒：热扰动 → 自动重规划（不说话）。
5. 6 秒：工作流一屏。

## 四、可选加分镜头

**「已满足则不动」** 是最能区分 Agent 与脚本的一段，60 秒版塞不进去时优先在 3 分钟版保留。

**夜间老人安全**（需额外约 40 秒）：在「主动服务」把卧室起身传感器和照度传感器绑上，
用控制台的照度注入把卧室调到 8 lx，再触发起身上升沿，展示有序路径灯点亮与人工接管 TTL。

## 五、录制提示

- 开录后停 2 秒再操作；切视图后停约 1 秒，方便剪辑。
- 生成计划的等待不要全剪掉——本地模型推理和安全校验是技术展示的一部分。
- 麦克风需要 localhost 或 HTTPS 页面；首次授权后重新长按。
- 建议 1920×1080，浏览器缩放 90%–100%。
- 正式录制前关掉无关通知，确认页面没有红色错误。
