# KDXF SpaceMind 赛题需求分析

## 评分点拆解

| 评审维度 | 分值 | SpaceButler 对应策略 |
|---|---:|---|
| 场景价值 | 20 | 聚焦返家舒适、老人夜间安全、峰电节能、多成员偏好冲突等真实家庭痛点 |
| 功能完备程度 | 25 | 空间感知、记忆召回、主动计划、多设备动作、确认机制、结果解释 |
| 技术可行性 | 20 | 复用旧项目 Home Assistant、MQTT、Docker、本地模型、状态回读能力 |
| 创新性 | 20 | 从命令式控制升级为空间主动服务和多成员偏好调和 |
| 商业价值 | 10 | 面向家庭、适老住宅、酒店式公寓、地产样板间和智能空间生态 |
| 应用前景 | 5 | 可扩展到多模态传感、日程、健康设备和第三方 IoT 生态 |

## 与旧项目的关系

`EdgeHome_Agent` 已经证明“设备执行闭环”可行，包括 Home Assistant 边界、MQTT 模拟设备、Docker 一键演示、受保护设备和验收证据。SpaceButler 不重复造底层控制，而是在其上补齐 SpaceMind 赛题更看重的主动服务层：

- 空间状态：从设备状态扩展到成员、活动、环境、时间段。
- 真实记忆：从会话记忆扩展到成员偏好和场景偏好。
- 自学习：基于显式反馈更新偏好，避免隐式画像带来的隐私风险。
- 主动服务：不等待命令，基于状态触发返家、夜间安全、节能方案。
- 多成员调和：当偏好冲突时生成折中计划并要求确认。

## 建议作品名称

**SpaceButler：面向家庭空间的主动智能管家 Agent**
