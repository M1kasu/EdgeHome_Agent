# SpaceButler 作品简介

SpaceButler 是一套面向家庭空间的主动智能管家 Agent。它不只响应“打开灯、关闭空调”等单点命令，而是持续理解家庭成员、空间环境、设备能力和偏好记忆，在合适时机主动生成可解释、可确认、可验证的空间服务计划。

## 核心场景

1. 返家舒适预备：识别成员返家，结合个人温度偏好、照度和设备状态提前调节空调与灯光。
2. 老人夜间安全：检测老人夜间起身，联动路径照明并降低跌倒风险。
3. 舒适节能平衡：在峰电时段结合室内外温差和在家状态，提出低打扰节能方案。
4. 多成员个性化：同一空间多人偏好冲突时，生成折中方案并要求确认。

## 创新点

- 从被动语音控制升级为主动空间服务。
- 使用显式反馈形成可审计家庭记忆，兼顾个性化与隐私。
- 用空间状态统一描述人、设备、环境与时间，支撑多场景规划。
- 复用 Home Assistant / MQTT / Docker 的可验证执行闭环，避免“模型说成功”。
