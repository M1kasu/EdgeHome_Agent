# 商业模式与落地

## 目标用户

- 有老人、儿童或多成员生活习惯差异的家庭。
- 智能住宅、酒店式公寓、长租公寓和地产样板间。
- 已部署 Home Assistant、Matter、MQTT 或品牌 IoT 设备的智能空间用户。

## 市场切入

1. 以“家庭空间主动管家”作为软件服务切入已有智能家居生态。
2. 与地产、养老公寓、酒店式公寓合作做样板间 Demo。
3. 面向设备厂商提供 Agent 规划、安全执行和记忆服务 SDK。

## 盈利模式

- 家庭订阅版：本地 Agent + 云端备份/模型升级。
- 空间项目版：按房间、户型或项目授权。
- 生态 SDK：向 IoT 厂商提供 Agent 能力组件。

## 落地优势

项目可先用 Home Assistant 和 MQTT 生态验证，再逐步接入 Matter、厂商品牌网关、日程、健康设备和多模态传感器。
