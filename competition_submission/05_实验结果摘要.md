# 实验结果摘要

所有数字均可回溯到 `assets/data/` 或仓库 `benchmark/results/`。不同实验的任务定义不同，表中不把路由接受、非空模型回复、Schema 合法和设备状态完成率混为同一“成功率”。

| 实验 | 指标 | 结果 | 环境 | 数据来源 |
| --- | --- | ---: | --- | --- |
| 双路径简单任务 | 快速路径平均延迟 | 12.652 ms | Q4_K_M、ctx2048、CPU、50 条自然语言任务 | `dual_path_results.csv` |
| 直接模型简单任务 | 平均延迟 | 643.195 ms | 同上 | `dual_path_results.csv` |
| 双路径简单任务 | 相对平均延迟降低 | 98.03% | 同上；仅比较路由响应 | 由同一 CSV 计算 |
| 双路径简单任务 | 路由接受 / 模型调用 | 35/50；0/50 | 同上 | `dual_path_results.csv` |
| 复杂规划 | Schema 合法 | 27/30（90%） | Q4_K_M、ctx2048、256 token、30 条任务 | `complex_schema_q4_ctx2048_full.outcomes.json` |
| Python 回归 | 通过数量 | 112 | Windows 测试环境 | 第 13 阶段质量记录 |
| 稳定性 | 配置窗口 / 样本 | 3,600 s / 60 | 本地只读核心工作负载 | `stability_1h_summary.json` |
| 稳定性 | 模型/检索/能耗失败 | 0 / 0 / 0 | 同上 | `stability_1h_summary.json` |
| 断网 | 本地模型健康检查 | HTTP 200 | Docker `--internal` 网络 | `offline_network_test.json` |
| 安全攻击 | 受保护设备服务调用 | 0 / 20 条攻击输入 | 隔离 HA Core、虚拟实体 | `safety_workloads.json` |
| 故障恢复 | 最终状态完成率 | 90% → 100% | 50 次隔离 HA 故障注入 | `execution_verification_comparison.csv` |
| 故障恢复 | 假成功率 | 10% → 0% | 同上 | `execution_verification_comparison.csv` |
| 本地知识检索 | 有证据成功 | 19/20 | 本地 FTS5、原创测试资料 | `knowledge_workloads.csv` |
| 能耗分析 | 成功调用 | 15/15 | 合成 7 天小时级能耗数据 | `energy_workloads.csv` |
