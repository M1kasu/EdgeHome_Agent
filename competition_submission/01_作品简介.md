# 智家端脑 EdgeHome Agent

副标题：面向全屋智能场景的端侧自主服务智能体

## A：技术创新型

面向智能家居中“复杂自然语言难以安全落地为设备操作”的问题，智家端脑 EdgeHome Agent 构建了端侧双路径智能体：简单中文指令走轻量意图与槽位路径，复杂目标由本地小模型生成结构化计划，再经安全校验、工具白名单和状态回读执行。系统结合家庭状态、场景模板、本地知识检索与确定性能耗分析，实现观影、离家、睡眠等跨设备协同。实测中，简单任务快速路径平均 12.652 ms，直接模型为 643.195 ms；复杂规划 Schema 合法率为 27/30。项目强调可验证执行和本地隐私，而非只生成自然语言答案。

## B：应用价值型

许多家庭要逐个操作灯光、空调和窗帘，复杂场景又需要手工配置规则。智家端脑让用户用一句生活化中文表达目标，例如“我要看电影了，空调不要低于25度”，系统结合家庭状态形成可检查的操作计划，调用设备后还会回读状态，避免“显示成功、实际没执行”。简单控制无需等待模型，复杂问题可查询本地设备资料、分析合成演示能耗数据并给出节能方案。它以端侧运行减少外发数据，并保留冰箱、路由器等关键设备保护边界。

## C：技术与应用平衡型（正式推荐，约 250 字）

智家端脑 EdgeHome Agent 面向“用户的生活化需求难以安全变成多设备协同操作”的问题，构建端侧自主服务智能体。系统把简单中文指令交给轻量快速路径，把观影、离家、睡眠等复杂目标交给本地模型规划；计划必须经过 Schema、安全规则和工具白名单，再由 Home Assistant 执行并回读状态。它还提供本地设备资料检索与确定性能耗分析。实测中，简单任务快速路径平均 12.652 ms，直接模型平均 643.195 ms；复杂规划 Schema 合法率为 27/30；一小时 60 次只读稳定性采样三类失败均为 0。项目以本地运行、可验证执行和关键设备保护为重点，为智能家居提供可审计的自然语言服务方式。
