# 现场演示脚本

## 演示前检查（按顺序）

1. 运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\healthcheck.ps1`，确认 Home Assistant 与 llama.cpp 均返回 HTTP 200。
2. 运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\reset_demo.ps1`，确认虚拟实体重置；冰箱与路由器为开启状态。
3. 打开 `http://127.0.0.1:8123`、Assist 对话页、实体状态页和日志页；确认 EdgeHome 已在当前 Assist 管道中选择为默认对话代理。
4. 执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\run_demo_tests.ps1 -SmokeOnly`，确认本地资料索引和能耗 CSV 可读取。
5. 打开 `assets/figures/` 与 `assets/data/`，作为模型慢、页面失败时的可复核备用材料。
