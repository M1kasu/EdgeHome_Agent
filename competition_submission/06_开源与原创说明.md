# 开源与原创说明

## 开源复用边界

| 组件 | 已有能力的用途 | 本项目的使用方式 | 许可证/说明 |
| --- | --- | --- | --- |
| Home Assistant | 实体状态、服务调用、自动化、仪表盘 | 作为受控设备执行和状态回读底座 | Apache License 2.0，详见上游 |
| Home LLM | 本地模型与 Home Assistant 对话集成基础、后端接口 | 在其基础上增量扩展 EdgeHome | 详见上游仓库许可与本仓库通知 |
| llama.cpp | GGUF 模型加载与本地推理服务 | 提供 OpenAI 兼容本地端点 | 遵循上游许可证 |
| SQLite FTS5 / Pydantic / Docker 等 | 本地索引、数据校验、运行环境 | 作为依赖使用 | 分别遵循上游许可证 |

## 本项目新增模块

- 中文快速路径、意图与槽位数据、双路径路由；
- 家庭状态快照、受限场景模板与结构化计划；
- Schema 校验、中文实体别名、工具白名单、受保护设备与冲突检测；
- 状态回读验证、受限失败恢复与资源感知调度；
- 本地 FTS5 知识检索、确定性能耗分析、多轮节能决策；
- 虚拟演示设备、标准任务集、性能/安全/离线/稳定性评测脚本与数据。

## 数据、模型与修改说明

- `knowledge/` 为原创测试资料；`datasets/energy/` 为固定种子生成的合成数据，不含真实家庭数据或第三方完整说明书。
- 项目未下载、嵌入或重新发布 GGUF 模型权重。第 13 阶段仅使用本机已有 `acon96/Home-Llama-3.2-3B` 衍生 Q4_K_M 文件进行本地测试。
- 模型及其训练数据可能带有非商业限制；比赛演示应遵循相应许可证，不应据此作商业化授权承诺。
- 具体第三方声明见根目录 `THIRD_PARTY_NOTICES.md` 与 `LICENSES.txt`；分发时应保留上游通知与修改说明。

## 合规承诺与限制

提交包不含访问令牌、用户 `.storage`、个人家庭状态、模型权重或真实账号信息。开源组件与新增模块边界见 [open_source_boundary.svg](assets/figures/open_source_boundary.svg)。本说明不构成法律意见；正式发布前应依比赛规则复核各依赖和模型许可。
