# 五分钟演示视频脚本（可信执行主线）

## 录制原则

- 主画面使用 Home Assistant 侧栏的 **EdgeHome 工作台** 与右上角 **Assist**；不要把开发者工具、终端、令牌或原始数据库作为主画面。
- 工作台中的“计划”和“回读验证”来自 `sensor.edgehome_last_execution`，设备卡片来自 MQTT Discovery 实体；模型回复、HTTP 200 或服务返回都不单独作为成功证据。
- 设备是 Docker 中运行的独立 MQTT 数字设备模拟器，状态持久化在 SQLite；不得说成真实物理家庭设备。
- 每段前执行 `scripts/reset_demo.ps1`。若使用预录片段，字幕必须标注“预录于同一演示环境”。

## 录制前后的操作清单

1. 在仓库根目录执行：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\healthcheck.ps1`。
2. 执行：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\reset_demo.ps1`，确认冰箱和路由器均为开启。
3. 打开 `http://127.0.0.1:8123/edgehome-workbench`；使用右上角 Assist 输入脚本中的指令。
4. 故障段结束后点击“清除窗帘故障”，再执行一次重置，避免影响后续片段。
5. 每个关键片段保留三项同屏证据：用户输入、工作台的计划/回读、对应 MQTT 设备实体的实际状态。

## 不要录入的内容

- `HA_TOKEN`、浏览器个人资料、账号信息、学校/学院/导师信息。
- 开发者工具中的手工改状态操作；那不能作为设备执行证据。
- 未标注来源的性能数字、未经独立外部验收的“通过”结论。
