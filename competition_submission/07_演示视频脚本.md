# 五分钟演示视频脚本

## 录制原则

- 只展示本地 Home Assistant、llama.cpp、虚拟演示实体和版本控制数据；不展示账号、令牌、个人家庭信息或学校信息。
- 屏幕同时保留“指令—计划/安全结果—实体状态”证据链；模型自然语言回复不单独作为执行成功证据。
- 每段录制前按 `11_现场演示脚本.md` 重置环境；失败备用镜头必须标注“预录于同一演示环境”，不得拼接为现场实时结果。

## 拍摄清单

1. 录制前执行 `scripts/reset_demo.ps1`，确认冰箱和路由器保持开启。
2. 每段都截取输入、状态前后、结构化/安全结果，不录入任何凭证。
3. 单独录制模型不可用、非法 JSON 和浏览器错误的备用片段。
4. 旁白以“本次测试”“虚拟演示实体”“受控断网条件”限定结论，不使用“完全”“绝对”“行业领先”。
